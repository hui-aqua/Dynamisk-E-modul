Dynamic Test Data Viewer

User guide for engineers and technicians reviewing rope test measurements.

Open the data viewer · Laboratory test procedure

Use this guide to inspect a completed test, choose a fitting range, enter specimen dimensions, and review the viewer’s estimated modulus. Stage and cycle boundaries are automatic estimates; confirm them against the test record.

1. Open a test workbook

  1. In the viewer’s left panel, choose an Excel or CSV test file, or drag the file onto the panel.
  2. Select the workbook from the file list. Choose the force and stretch measurement sheet from the tabs above the plot.
  3. Check the specimen name and measurement units shown above the plot. The viewer keeps selected files in your browser; it does not upload them.

If a sheet has no recognizable force and stretch columns, the viewer shows its rows as a table. The Results summary may also be unavailable if its headings cannot be read; you can still inspect the curve and enter engineering values manually.

2. Review the stages and dynamic cycles

The left panel lists estimated test stages and dynamic cycles. Select a stage or cycle to highlight its points and set the fitting range. A cycle marked with an asterisk is an incomplete final cycle with no detected return to the reference load.

Check the force targets

  • T_design target (N) is the load target used to detect the stages. It may differ from measured F_max. Enter the intended test target and leave the field to update the estimates.
  • T_design buffer sets the boundary below T_design. For example, a 1% buffer places it at 99% of T_design.
  • T_ref (N) is the reference load used to detect low-load returns.
  • T_ref buffer sets the return band above T_ref as a percentage of the force span between T_ref and T_design.

Changing a target or buffer refreshes the stage and cycle estimates. Your target edits stay in effect while you switch sheets in the same workbook; selecting another workbook starts with that test default. Review the highlighted points, especially when the measured peak does not equal T_design.

3. Choose and fit a range

  1. Select a detected cycle in the left panel, or enter the first and last point numbers. You can also click a start point and then an end point on the plot.
  2. Choose the fitting mode, then click Calculate slope. The fitted points are highlighted in red and the fit summary appears above the plot.

For Loading path and Unloading path, choose a Path section: 0–100% uses that entire path; the four quarter options fit only 0–25%, 25–50%, 50–75%, or 75–100% of it.

The result reports the range used, the force–stretch or force–strain fit, and its x-intercept. The fit box can scroll when a result is longer than the visible area.

4. Set specimen dimensions and review E

  • Enter Diameter [mm] or Area [mm²]. The viewer calculates the other value assuming a circular cross-section. You can replace either value directly.
  • Enter L0 [mm] if the workbook value is missing or incorrect. Your entry is used in preference to the value read from Results.

For a plot whose horizontal axis is stretch in millimetres, the viewer adds the x-intercept to L0, including a negative intercept. If the adjusted L0 remains positive, it calculates E = slope × adjusted L0 / area.

For a plot whose horizontal axis is strain in percent, it calculates E = slope × 100 / area; L0 is not used for that calculation. The result is reported in MPa and GPa when force is in newtons and area is in mm².

5. Change the plot view and export

  • View1 fits the plot to the data’s minimum and maximum stretch and force.
  • View2 starts both axes at zero and ends them at the data maximums.
  • Reset zoom restores the chart’s original view. Use the mouse wheel to zoom.
  • Export current sheet as CSV saves all valid force–stretch or force–strain pairs from the selected sheet. The on-screen table displays up to 5,000 rows.
  • Clear removes the loaded files and resets the viewer’s selections and input fields.

Before using a calculated value in engineering analysis, confirm the selected points, force targets, units, specimen dimensions, and L0 against the test record.
