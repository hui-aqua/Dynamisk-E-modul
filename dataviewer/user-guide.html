Dynamic Test Data Viewer

User guide for loading rope test workbooks, reviewing dynamic cycles, fitting a curve, and estimating Young’s modulus.

Open the data viewer · Open full laboratory test procedure

1. Load test data

  1. Open the viewer and choose one or more .xls, .xlsx, .xlsm, or .csv files, or drag files onto the file panel.
  2. Select a workbook in the file list, then select the measurement sheet using the tabs above the plot. The viewer looks for columns named Strain and Force or Standard force, with units in the workbook.
  3. Files are read in your browser and are not uploaded by the viewer. The viewer’s spreadsheet and chart libraries load from public CDNs, so an internet connection is needed.

To run a local preview on Windows, open PowerShell in the dataviewer folder and run ./preview-local.ps1. Keep that window open while testing; press Ctrl+C to stop the server.

2. Review workbook information and stages

When a Results sheet has recognizable parameter headings, the viewer displays its values above the plot. If it cannot read those headings, the measurement plot and manual engineering inputs can still be used.

The left panel lists estimated test stages and dynamic cycles. Select a stage or cycle to highlight its data and set the point range for fitting. Detection boundaries are estimates; compare them with the instrument record.

Set force targets

  • T_design (N): the design target used for stage and cycle detection. It defaults to a detected value but can be edited when the target differs from F_max. Changing it reruns detection.
  • T_design buffer (% of T_design): moves the design boundary below T_design. For example, 1% uses 0.99 × T_design as the boundary.
  • T_ref (N): the reference or low-load target used to locate returns.
  • T_ref buffer (% of force span above T_ref): sets the return band above T_ref. The force span is T_design − T_ref; a 1% buffer gives T_ref + 0.01 × (T_design − T_ref).

Change a target or buffer and leave the input to refresh the stage and cycle estimates.

3. Navigate and select a fitting range

  • Use the mouse wheel to zoom. Click two points on the plot to select a range, or enter the first and last point numbers in the range fields.
  • Select a detected stage or dynamic cycle in the left panel to use its estimated bounds.
  • Reset zoom restores the original chart view. View1 fits both axes to the data minimum and maximum. View2 starts both axes at zero and ends at their data maximum.

Fit cycle range

OptionWhat it fits
Full cycleAll points in the selected point range.
Loading pathThe first half of the selected range, as force rises through the cycle.
Unloading pathThe second half of the selected range, as force falls through the cycle.

For Loading path or Unloading path, the Path section menu appears. 0–100% uses the full selected path. The other choices fit and highlight the indicated quarter: 0–25%, 25–50%, 50–75%, or 75–100%.

Click Calculate slope after choosing a range. The fit result reports the fitted points, stretch and force span, linear equation, and x-intercept. The selected fit points are highlighted on the plot.

4. Estimate Young’s modulus

  • Enter the rope Diameter [mm] or Area [mm²]. The other field is calculated assuming a circular cross-section.
  • Enter L0 [mm] if the Results sheet is missing or its value is incorrect. A manual L0 takes precedence over the workbook value.
  • The viewer adds the fit’s x-intercept to L0, including a negative intercept. It calculates E when the resulting adjusted L0 is positive and an area is available.

The calculation is E = slope × adjusted L0 / cross-sectional area. With force in newtons and length and area in millimetres, E is reported in MPa and GPa. Review the selected fit range and input values before using the estimate.

5. Inspect and export data

The data table shows up to 5,000 valid plotted rows. Click Export current sheet as CSV to export all valid force–stretch pairs from the selected sheet. Use Clear to remove loaded workbooks and reset the viewer’s inputs and results.

Stage and cycle detection provides convenient estimated boundaries. Confirm the selected points, targets, units, diameter or area, and L0 against the test record before using calculated values in engineering work.
